# submission/

Drafts for the project submission form, one file per field, plus the demo script. Copy the final text into the Project tab on the team page.

**Official guide:** <https://www.spaceappschallenge.org/resources/project-submission-guide/>

The guide is the source of truth for the form fields, the demo limits (at most 7 slides or a video of at most 30 seconds), how to share files (public links with no login) and the submission checklist. A summary is in [../research/01-event-2026.md](../research/01-event-2026.md), section "Project submission requirements". If the guide and our notes disagree, follow the guide.

| File | Form field |
|------|------------|
| [01-name-and-summary.md](01-name-and-summary.md) | Project Name, High-Level Project Summary |
| [02-links.md](02-links.md) | Link to Project Demo, Link to Final Project |
| [03-detailed-description.md](03-detailed-description.md) | Detailed Project Description |
| [04-si-use.md](04-si-use.md) | Use of Super Intelligence (SI) |
| [05-data-and-references.md](05-data-and-references.md) | NASA Data, Space Agency Partner Data and Other References |
| [06-demo-script.md](06-demo-script.md) | The demo (not a form field; the link goes in field 2) |
| [07-form-paste-ready.md](07-form-paste-ready.md) | Paste-ready text for every field of the Project tab, in the order of the page (name, summary, links, details, SI boxes, NASA data and other references) |
