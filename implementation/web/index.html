SkylinerSPHEREx

See a patch of sky change over time

Real infrared images from NASA’s SPHEREx mission, played in time order like a short video, so you can look for something that moves.

The preparation service is not running yet. Positions that were prepared before open without it. For a new position, start it with ./start.sh in the project folder: this page waits for it and carries on by itself.

Or try one of NASA’s test targets:
  • A position that was looked at before opens at once.
  • A new position is fetched from NASA’s public archive while you wait. That takes a few minutes, with a progress bar, and then it stays ready.
  • This page shows images only. It does not detect or name moving objects.
