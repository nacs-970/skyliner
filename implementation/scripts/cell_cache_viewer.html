Cell cache viewer: WISE 0855, SPHEREx DR1 cutouts

Real SPHEREx cutouts (NASA/IPAC IRSA), put on one pixel grid. "Stored" is what the lossy cell cache gives back, not the original. The cache drops frame noise in cells that look unchanged and rounds the rest, so use the original for any measurement. Frames are in time order. The wavelength at the target is in the label: it changes a little from frame to frame (and a lot if frames come from different detectors), so some brightness change between frames is expected.
